# 对话式创作指南（中文）—— 说主题，出片子

> 这份文档回答的是：**「我想让 agent 帮我做一条视频」该怎么开口、会发生什么、要花多少钱。**
> 不是「怎么敲脚本」——那是 `docs/TESTING-GUIDE-zh-CN.md`。
>
> 所有命令与能力数字均为 **2026-09-24 本机实测**。

---

## 1. 一句话就够：你只要说主题

在**当前这个对话里**直接说你要什么就行。agent 会自己读 `AGENT_GUIDE.md` → 匹配 pipeline →
预检能力 → 逐阶段推进。**你不需要知道任何命令。**

### 可以照着说的例子（本机当前能力下**真的能跑**）

**① 免费 · 真实素材纪录片**（推荐第一次试这个，**0 元**）

> 做一条 60 秒的纪录片式蒙太奇，主题是「凌晨四点的城市」。**只用真实素材**，
> 不要旁白，挽歌式基调，配乐要有。

**② 免费 · 真实素材（NASA/档案）**

> 用公开档案素材做一条 45 秒的片子，讲人类怎么一步步看到地球全貌，配乐，不要旁白。

**③ 免费 · 图文解说（示意图 + 免费配音）**

> 做一条 45 秒的中文动画解说，主题是「为什么天空是蓝的」，要旁白和字幕。

**④ 付费 · AI 生图解说（约 $0.30–0.60）**

> 做一条 30 秒的中文动画解说，讲清楚 CRISPR 基因编辑的原理，
> 用 AI 生成的示意图，要旁白和字幕，成本控制在 $1 以内。

## 2. 说出口之后，会发生什么

agent 按 **Rule Zero**（所有生产必须走 pipeline）推进。以 `animated-explainer` 为例，
共 8 个阶段，**5 个会停下来等你批准**：

| # | 阶段 | 谁在等 | 你会看到什么 |
|---|---|---|---|
| 1 | `research` | 自动 | 选题调研：至少 3 个数据点、3 个角度、5 个来源 |
| 2 | `proposal` | ✋ **等你批** | 3 个**不同**概念 + 逐项成本 + 运行时选择 |
| 3 | `script` | ✋ **等你批** | 分场景脚本 + 配音演出方案 |
| 4 | `scene_plan` | ✋ **等你批** | 分镜表 |
| 5 | `assets` | ✋ **等你批** | 生成素材（**这一步开始花钱**）|
| 6 | `edit` | 自动 | 剪辑决策（cuts、字幕、混音参数）|
| 7 | `compose` | 自动 | 渲染成片 |
| 8 | `publish` | ✋ **等你批** | 发布 |

**关键**：在第 2 步（proposal）你就能看到**成本明细**和**运行时选择**，
不满意可以直接叫停 —— 这时候**还没花一分钱**。

> `documentary-montage` 只有 5 个阶段（`idea → scene_plan → assets → edit → compose`），
> 更短更快。**免费真实素材走的就是这条。**

### ✅ AI 生视频现在可以走官方流程了（C1b，2026-09-24）

之前 `video_generation` 是 **0/26**，AI 动态视频只能脚本直调、进不了流水线。
现在 `apiyi_seedance_video` 已注册为一等工具，`video_selector` 能自动发现它。

**意味着**：可以正常说「用 Seedance 做 AI 动态画面」，asset 阶段会自动路由过去。

**价格**（16:9、5 秒、无输入视频）：
`mini` 480p ¥1.16 / 720p ¥2.50；`fast` ¥1.86 / ¥4.00；`standard` 480p ¥2.31 / 720p ¥4.97 / 1080p ¥12.39。

**三条限制**（工具已内建处理，但你要知道）：
- **提交即扣费**，后续失败不退 → 先用 `mini + 480p + 4s` 验证（约 ¥0.93）
- **无法取消任务** —— 该网关没有取消接口（工具会明确报错，而不是假装成功）
- **没有 `2.5` 版本** —— 该网关只卖 2.0 的 standard / fast / mini

另外 `pexels` / `pixabay_video` / `unsplash` 仍**不可用**（缺免费 key）。
如果你愿意去申请免费的 `PEXELS_API_KEY` 填进 `.env`，真实素材库会大很多。

## 4. 三条推荐路线（按「值得先试」排序）

### 路线 A · 免费纪录片蒙太奇（**最推荐**，0 元）

**你说**：
> 做一条 60 秒的纪录片蒙太奇，主题是「凌晨四点的城市」。只用真实素材，不要旁白，挽歌式基调，配乐要有。

**为什么最推荐**：
- 素材**免密钥**（archive.org / NASA / Wikimedia 等 7 个源实测可用）
- 全程 **0 元**
- 只走 5 个阶段，最快看到成片
- `direct_clip_search` 实测 `available`

**风险**：公开档案素材画质参差不齐（尤其 archive.org 的老胶片），
且**没有旁白**时全靠剪辑和配乐撑节奏，对 `edit` 阶段要求高。

---

### 路线 B · 免费图文解说（0 元，但视觉受限）

**你说**：
> 做一条 45 秒的中文动画解说，主题是「为什么天空是蓝的」，要旁白和字幕。

**为什么可行**：配音免费、字幕免费、示意图免费（Mermaid）、渲染免费。

**关键限制**：`image_selector` 唯一的 provider 是 `apiyi`（付费）。
所以**要么花 $0.03/张用 AI 图，要么完全不用 AI 图**，靠：
- `diagram_gen`（流程图 / 架构图 / 数据图）
- `code_snippet`（代码画面）
- Remotion 内置组件（文字卡、数据卡、图表）

README 里「零密钥」示例（"why is the sky blue"）描述的正是这条路。
**但要注意**：纯文字卡 + 图表做 45 秒，视觉会比较单调 —— 这正是 LDWS 项目当初被用户
否定「像对着几张图说话」的原因（见 `USAGE_NOTES_zh-CN.md` §7）。

---

### 路线 C · 付费 AI 生图解说（约 $0.30–0.60，质量最好）

**你说**：
> 做一条 30 秒的中文动画解说，讲清楚 CRISPR 基因编辑的原理，
> 用 AI 生成的示意图，要旁白和字幕，成本控制在 $1 以内。

**成本**：30 秒 ≈ 8–12 个镜头 ≈ 8–12 张图 × $0.03 = **$0.24–0.36**。
LDWS 的历史成本可参考：5 图 + 8 个 Seedance 片段 ≈ $1.46。

**建议**：先在 proposal 阶段看 agent 报的成本，再决定要不要削减镜头数。

---

### 路线 D · 付费 AI 动态视频（新增，¥0.93 起/条）

**你说**：
> 做一条 15 秒的 AI 动态视频，主题是「云雾中的漂浮图书馆，黄昏金光」，
> 用 Seedance，先给我看 prompt 和成本再提交。

**成本**：`mini + 480p + 4s` ≈ **¥0.93**/条（最省）；`standard + 1080p + 5s` ≈ **¥12.39**/条。

**⚠️ 三条必须知道的规则**：

1. **提交即扣费，失败不退** —— 所以**先用 mini + 480p + 4s 验证** prompt，满意再升级参数
2. **无法取消任务** —— 该网关没有取消接口；工具会明确报错，而不是给你一个假的"已取消"
3. **没有 2.5 版本** —— 只卖 2.0 的 standard / fast / mini

**注意**：Seedance **自带配音和音效**（默认开启）。prompt 里把台词写在双引号内即可生成同步人声，
不需要另外做 TTS。若想后期自己配音，加 `--no-audio` 关掉。

## 6. 让结果更好的说话方式

**说清楚这几点，agent 的产出会好很多**：

| 要素 | 例子 |
|---|---|
| **时长** | 「45 秒」 |
| **受众** | 「给高职学生看」「给中学生看」 |
| **调性** | 「挽歌式」「轻快」「严肃教学」 |
| **要不要旁白** | 「要旁白和字幕」/「不要旁白，纯音乐」 |
| **素材来源** | 「只用真实素材」/「用 AI 生成示意图」 |
| **预算上限** | 「成本控制在 $1 以内」 |
| **画面风格** | 「横版 16:9」「像对着几张图说话不要」 |

**反面例子**：
> ❌「做个视频」 ← agent 只能反问你要什么

**正面例子**：
> ✅「做一条 45 秒的中文动画解说，给高职学生讲车道偏离预警系统怎么工作，
> 要旁白和字幕，用 AI 生成的示意图，横版，成本控制在 $1 以内」

## 7. 关于「重做」和「改」

不满意时**不用重说一遍**，直接说改什么：

| 你说 | agent 会做 |
|---|---|
| 「第 3 个镜头换掉」 | 只重做那一处 |
| 「旁白太慢，重配」 | 只重跑 TTS |
| 「字幕对不上」 | 重跑字幕链路 |
| 「整个重做，但换成 XX 风格」 | 回到 proposal 重新提案（**会再花钱**）|
| 「接着做」 | 从下一个未完成阶段继续 |

**已有项目可以直接续做或重渲染**（素材都在磁盘上，**0 元**）：
`projects/ldws-teaching/` 是唯一走完 8 阶段的真实项目，16 个素材全部完好。

> 重渲染 LDWS 的说法：
> 「重渲染 ldws-teaching 的 compose 阶段，用现有素材，**不要重新生成任何素材**」
